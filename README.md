\# Auction Arena



\### Where Strategy Meets Bidding



Auction Arena is a browser-based Game Theory project that demonstrates the \*\*Vickrey Auction (Second-Price Sealed-Bid Auction)\*\* through an interactive strategic bidding game.



The player competes against three computer bidders across 8 auction rounds.



\## Features



\- 8 auction rounds

\- 1 human player vs 3 computer bidders

\- Private player valuation

\- Hidden computer valuations

\- Strategic bidding

\- Vickrey second-price auction mechanism

\- Highest bidder wins

\- Winner pays the second-highest bid

\- Utility calculation

\- Win rate and total utility tracking

\- Final performance evaluation

\- Play Again / New Game

\- Responsive desktop, tablet and mobile design



\## How It Works



1\. The player receives a private valuation for the current item.

2\. The player submits a bid.

3\. Three computer bidders generate their bids internally.

4\. The highest bidder wins.

5\. The winner pays the second-highest bid.

6\. Player utility is calculated.



\### Utility



\*\*Utility = Private Valuation − Payment\*\*



If the player loses the auction, the player's utility is \*\*0\*\*.



\## Game Theory Concepts



This project demonstrates:



\- Strategic Bidding

\- Private Valuation and Preferences

\- Utility

\- Mechanism Design

\- Vickrey Auction

\- Second-Price Sealed-Bid Auction



\## Performance Evaluation



The final performance is primarily evaluated using \*\*Total Utility\*\*, with \*\*Rounds Won\*\* and \*\*Win Rate\*\* as supporting indicators.



Winning more auctions does not necessarily mean better performance. The objective is to make efficient bidding decisions that maximize overall utility.
